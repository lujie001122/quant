# ETF量化交易系统 v3.3

7只ETF共享220k资金池，macOS全自动量化交易。回测+实盘一体化。

## 环境要求

- Python 3.11
- macOS（同花顺客户端 + EvolvingSim + cliclick）
- 依赖见 `requirements.txt`

## 安装

```bash
git clone git@github.com:lujie001122/quant.git
cd quant
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

验证：`python3 backtest_bt.py --period=3m`

## 策略概述

### 建仓（6通道，全部强制 price > MA20）
- RSI抄底 / MACD金叉追涨 / 突破追 / 分批建仓 / 确认加仓 / 试探仓
- 资金：共享池220k，单只上限50%

### 出场
- **均价止损12%**：成本×0.88
- **保本止盈**：浮盈≥10%激活，回落至成本+2%清仓
- **分级止损**：连续2天破MA20→减30%→DIF<0→再减30%→MACD恶化→清仓
- **移动止盈**：8%基础+15%峰值回撤5%
- **硬止盈30%**：基准价×1.30

### 做T（v2026-08-11）
- **数据源**：5分钟分时K线，所有指标（ATR/RSI/MACD(5,34,5)）均5分钟数据
- **评分**：RSI<45买入/>55卖出，3项共振≥2分触发
- **极端兜底**：RSI>75仅卖出，RSI<25仅买入
- **趋势过滤**：MA20斜率>0.1%禁T卖，<-0.1%禁T买
- **配对挂单**：ATR×1.1，数量=总持仓×30%，价差×量>10元
- **运行时间**：11:00后，每日2-3次
- **防御过滤**：159611电力ETF为防御标的

### 挂单管理
- 未成交挂单 → 下次cron撤旧挂新
- 同方向同品种 → 撤单后重新挂
- 已成交 → 跳过不重复

## 执行流程

```
cron → signal_generator.py --execute
  ├─ 拉行情 → 生成信号
  ├─ 检查挂单（未成交→撤旧挂新，已成交→跳过）
  ├─ 限价修正（买≤现价，卖≥现价）
  ├─ 调 trade.py 下单
  │   ├─ 成功 → 写 .last_executed.json
  │   └─ 失败 → [ALERT] + .trade_errors.json
  └─ AI 只通知，不干预
```

## 同花顺连接

- `trade.py` 通过 `open -a` + `cliclick` 激活同花顺窗口
- 每次调 EvolvingSim 前自动清理僵尸进程 + lock.json
- 子进程15秒超时保护，超时后 kill + 清理
- 3次重试 + 窗口激活
