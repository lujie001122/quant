## 策略逻辑

### 建仓（6通道）
1. RSI超卖+MACD金叉
2. RSI超卖+红柱
3. RSI超卖+AO反转
4. 多头排列回踩MA20
5. 破MA20+MACD支撑
6. RSI极值(30以下)反弹

### 止损（分级）
- Level 1：MACD绿柱→减活动仓20%
- Level 2：破MA20→减活动仓30%
- Level 3：MACD死叉→清仓

### 止盈
- 移动止盈7%（回撤甜点）
- 趋势止盈：浮盈>15%破MA5卖活动仓
- 硬止盈60%

### 做T
- 5分钟K线MACD
- RSI<50买入，>50卖出
- 配对挂单，固定价差

### 网格
- 倒金字塔5档买入
- 3档卖出
- 动态间距（ATR×权重）

### 轮动
- 每周一扫描49只ETF
- 4周/8周动量加权排名
- 4攻1守选池

## 优化铁律

1. **每次只改一条**→跑回测→有效保留/无效回滚
2. **40+条优化唯一有效**：去掉512170医疗ETF（2025+6.1%）
3. **7%固定回撤是甜点**：5→7有效，7→8失败，ATR跟踪止损全失败
4. **限制买入/加速卖出都伤趋势市**——R²/MA120乖离/卖出冷却/放量卖出/相关性过滤/Score加权全失败
5. **回测"bug"是局部最优产物**——P0-1/2/7修复反而变差，不强行统一

## 下单铁律

- 只按信号价挂单，不追价
- 股数≥5000股，100倍数取整
- 买入限价≤卖一价，卖出限价≥买一价
- 同花顺返回值不可信，下单默认成功
- 每日买入上限1次（ATR>5%时2次），做T上限2次（ATR>5%时3次）
