# 每日复盘格式

## 数据来源
- 持仓/资金: `python3 ths_client.py holdings` / `account`
- 成交: `python3 ths_client.py entrust`
- 行情: akshare `fund_etf_hist_em(symbol=code, period='daily', adjust='qfq')`
- 舆情拦截: `sentiment_block.json`

## 报告格式

```
📊 每日复盘 | 日期

📈 今日行情：
- 159516 半导体设备：开盘X 收盘X 涨跌幅X%
- 515880 通信：...
- 588170 科创半导体：...
- 159532 ETF：...
- 515050 中证全指：...

💰 今日操作：
- 买入 XXX 数量@价格 → 原因
- 卖出 XXX 数量@价格 → 原因
- （如无操作：今日无交易）

⚠️ 操作不完善之处（如有）：
- 例：信号延迟导致买入价偏高
- 例：止损不及时，应提前X分钟执行
- 例：做T方向错误，应先卖后买
- （如无问题：今日操作无明显问题）

📋 当前持仓：
- 159516 半导体设备：XXX股@成本价 浮亏/盈X%
- ...

🔮 今日加减仓/做T逻辑回顾：
- 为什么加仓/减仓：技术指标依据
- 做T逻辑：买入/卖出做T的原因
- 舆情拦截影响：如有

📰 赛道涨跌原因分析：
- 半导体：涨/跌原因（政策/事件/资金面/技术面）
- 通信：...
- ...（每个赛道一句话）
```

## 舆情拦截判定标准
- **利空**（拦截加仓）：政策打压、行业监管、重大负面事件、制裁、业绩暴雷
- **中性**（不拦截）：技术性回调、短期波动、无明显方向
- **利好**（不拦截）：政策扶持、行业利好、重大技术突破、资金流入、业绩超预期

**关键要求**：利好和利空都必须写明具体原因和事件，不能只写"利好"或"利空"两个字。例如：
- ❌ "半导体：利好"
- ✅ "半导体：利好 — 国产替代政策加码，大基金三期注资落地"
- ✅ "通信：利空 — 运营商资本开支缩减，5G建设放缓"

舆情早报格式中必须包含：
- 🟢 利好关注（如有）：标的 + 具体原因和事件
- ⚠️ 利空拦截（如有）：标的 + 具体原因和事件
