# 研究：让赢家更大更久（H1–H5）

- 分支 `research/hold`（main 未动，HEAD 仍是 9bbac41）
- 窗口 2019-01-01 → 2026-11-13，`--momentum=simple`，数据 `data/kline_qfq` 本地腾讯 qfq 缓存（26 只，日志尾部有 `[数据源] 腾讯qfq本地缓存×26只`）
- 基线复现：年化 +10.23% / 回撤 12.86% / 夏普 0.66 / 714 回合 —— dump 与归因数字逐项对齐
- 每条假设单独开/关；每个配置 ~7.5s，共 118 次真实回测（其中 walk-forward 33 次）

## 0. 先修两个前提（否则实验会做错方向）

1. **基线不是"跌出 TOP-N 就清仓"，是跌出 TOP-2N 才清仓。**
   `backtest_bt.py` 集中金字塔分支：`top_drop = ranked[:top_n*2]`，`top_n=5` → 退出阈值是 TOP-10。
   所以 H1 实际测的是"比 2N 更宽（3N / 加趋势门槛 / 先减半）"，不是"从 N 开始容忍"。
2. **e1 的"激活阈值 3.5%"在本引擎是死参数**：它只写进 `ps["reached_activation"] → pos.reached_8pct`，而 `risk_manager` 消费的是 `reached_8pct_ladder`（阶梯止盈自己置位）。
   实证：`激活6%/锁盈12%` 与 `只放宽锁盈12%` 两个配置 644 回合、+11.07%/0.72 完全相同 → H2 里"放宽激活"恒等于无效，只有"锁盈(lockin)"有效。
3. **H3 的"单票上限 50%→70%"在本回测资金模型里不 binding**：下单按 `fund_per_etf(44,000) × 比例`，单票打满 = 0.5+0.3+0.3 = 1.1×44k = 48.4k ≈ 总资金 22%，永远碰不到 50%/70% 上限。
   实证：`--pos-cap=0.70`、`--order-cap=0.70` 两个配置与基线**逐字节相同**。
   所以"让赢家更大"只能用真实绑定的杠杆测：首笔比例、加仓单批比例、加仓批次数。

## 6. 算术上界（回答"20% 到底要什么"）

用基线回合台账做线性近似（220,000 起始、7.87 年）：

| 情形（都是事后作弊） | 年化 |
|---|---|
| 基线 | +10.2% |
| 事后把所有 31 天+ 单仓位放大 1.5x | +14.0% |
| 事后把所有 31 天+ 单仓位放大 2.0x | **+16.9%** |
| 事后把所有 31 天+ 单仓位放大 3.0x | +21.5% |
| 事后删掉全部 ≤10 天亏损单（-230,134） | **+16.1%** |
| 两者都做（删亏损 + 长单 2x） | +20.9% |

结论：**20% 需要"事前知道哪些单会走长 + 给它们 2 倍仓"同时成立**。
单靠"让长单更大更久"这一类参数改动，实测天花板是 +11.8%（锁盈11%），距离 20% 差 8pp 以上。

### 7.3 逻辑回归（6 特征，2019-2023 训练 → 2024-2026 检验）

- 训练段 AUC = **0.683**（看起来能识别）
- 检验段 AUC = **0.462**（等于随机）

标准的"样本内拟合、样本外归零"。**结论：长单事前不可识别，是运气 + 行情给的，不是信号。**

### 7.4 落地验证：真按"低波动"过滤会怎样

H5a 只买 vol≤1.2%/日：31 天+ 笔数 72→53、31天+ 贡献 269k→121k、年化 +10.23%→**+4.85%**。
H5e 低波动+锁盈12%+前8日：回撤压到 **4.79%**（全表最低）、夏普 0.74（全表最高），但年化只有 +6.39%。
→ 低波动是"低回撤"的钥匙，不是"高收益"的钥匙。用它换长单数量是负期望。

## 8. 结论

**夏普能到多少**：基线 0.66。所有改动里最高是 0.75（锁盈11%），95% CI [-0.125, +0.302] 跨 0。
能说的只有一句：**0.66 是这套结构的天花板附近，±0.08 之内动不了它**。要 1.0+ 必须换结构（择时/仓位模型/标的空间），不是调这几个参数。

**年化能到多少**：基线 10.23%。最好单改动 +11.79%（锁盈11%），最好叠加 +11.17%（锁盈12%+前8日+3N），全部在噪声内。
**20% 在本结构下不可达**：即使事后知道哪些单走 31 天+ 并给 2 倍仓也只有 16.9%；20% 需要"删掉全部短亏损单 + 长单 2 倍仓"同时作弊。

**哪些能上实盘**：
- **锁盈 7%→12%（`trail_lock`）**：唯一有因果机制、且回撤同步改善（12.86%→11.39%）的改动。年化 +0.84pp/夏普 +0.06 在噪声内，不构成"已验证"，但它是"低风险、机制清楚"的那一类 —— 建议上，且按"未证伪的实验"对待，实盘小额并行跑 3 个月再定。
- 其余全部不建议：它们的收益来自个别年份（2025/近9月）和个别格点。

**哪些别碰**：
- H1 全部（-0.26 ~ -7.86pp）：放宽换仓 = 把该砍的亏损单留下，31天+ 变多但总收益变差。
- H3 全部（-3.14 ~ +0.08pp）：赢家加仓/更大单票/更多批次，全部恶化风险收益；"单票上限"在本引擎根本不 binding。
- H4 除 8 日外全部，且 7 日与 8 日差 4pp → 尖峰，别上线。
- H5 波动率过滤（-3.9 ~ -5.4pp）：换长单数量是负期望。
- ATR 3.5/4.5、gap 放宽（-0.5 ~ -1.8pp，回撤升到 18%）。
- **walk-forward 自动选参**：它比"一直用基线"差 3pp。
