## 利润流失点 #1: 网格卖出在上涨中不断减仓 ⭐⭐⭐⭐⭐

**这是最大的利润流失源。**

网格策略在上涨趋势中持续触发卖出，相当于在牛市中不断减仓。

### 影响量化
- 网格卖出+确认加仓形成了"卖低买高"的循环
- 例如 159516: 4/27 @0.488 卖28,900股 → 6/25 @0.851 确认加仓买回8,100股
- 每轮网格卖出约减少 60-70% 的持仓，剩余筹码在移动止盈触发时已很少

## 核心矛盾总结

```
┌──────────────────────────────────────────────────────────────┐
│  矛盾：放宽卖出 → 2026变差，但当前卖出在牛市中频繁减仓       │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  网格卖出: 上涨中不断触发 → 持仓持续缩水 → 涨到顶时已没仓位  │
│  移动止盈: 7%回撤触发 → 清仓后价格继续涨60%+                 │
│  追高回补: 清仓后空仓11天 → 重新入场已贵15%+                 │
│                                                              │
│  这三者叠加 = 牛市赚不到大钱的根本原因                       │
└──────────────────────────────────────────────────────────────┘
```

## 关键洞察

**入场不是问题，持仓管理才是。**

1. 入场价 0.4510 → 如果持有到7/1峰值 1.0530 = **+133.5%**
2. 如果持有到期末 0.7050 = **+56.3%**
3. 策略实际赚了 **+26.14%**（含两只ETF的共享资金池）

**利润流失的主要路径：**
- 网格卖出在上涨中减仓 → 持仓从146,300股缩到43,100股 (第1轮)
- 移动止盈清仓跑在回调中 → 错过后续60%+涨幅
- 重新入场时已追高15%+

**不改变卖出逻辑的方向：**
- 问题不在卖出信号本身，而在**网格卖出与上涨趋势的冲突**
- 应该考虑在明确的上涨趋势中（如多头排列+MA20斜率>0.5%）**禁用/减弱网格卖出**
- 或者将网格卖出与趋势强度挂钩：趋势越强，网格间距越大/卖出越少
