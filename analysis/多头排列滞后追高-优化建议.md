# 多头排列滞后追高问题 — 优化建议分析

## 问题诊断

**核心矛盾**：当前策略要求 `MA5>MA10>MA20`（完整多头排列）才允许建仓。这是一个**确认型指标**，等三条均线完全排列好时，价格通常已经上涨了 5-15%。以 3-6 月半导体翻倍行情为例，等 MA5>MA10>MA20 确认时，最佳入场窗口早已关闭。

**已证伪的方向**（不可重试）：
- ❌ 去掉 MA20（MA5>MA10>MA20 → MA5>MA20）：2025 +20%→+5%，2026 +30%→-0.8%，假突破大量入场
- ❌ 合并 7 通道为 3 通道：2026 年化 -24.85pp，丢失多样性保护
- ❌ RSI>65 防追高：动量排序选出强者 → RSI 过滤踢掉强者 → 剩下不温不火
- ❌ MA20 趋势完全禁用卖出：6 月有效但 1 年恶化，回调初期 MA20 仍在上升
- ❌ 放宽卖出 7 条全部失败

**已证实的正确方向**（来自 skill 中的核心洞察）：
> "池子仍按动量选（选强者），但入场时机等回调（RSI 从高位回落到 60 以下再建仓），而不是把强势标的踢出池子"

**策略基线**（2026-08-25）：
- 2025 全年：+20.29% / 回撤 9.01% / 夏普 1.16 / 35 笔 / 51.6% 胜率
- 2026 至今：+29.79% / 回撤 8.24% / 夏普 2.13 / 20 笔 / 50% 胜率
- 15 个月：+45.67% / 年化 35.05% / 夏普 1.70

## 优化建议

### 建议 1：新增「强势股回调」入场通道（🏆 最推荐）

**具体修改**：
在 `strategies/rsi_macd.py` 的建仓逻辑中，**在多头排列检查之前**新增一个早期入场通道（通道 0）：

```python
# 通道0: 强势股回调入场 (RSI从高位回落+站MA20)
# 不要求多头排列，但要求RSI近期曾>70（证明是强势股）
if pos.build_phase == 0 and not bullish_align:
    rsi_was_strong = any(r > 70 for r in rsi_history[-10:])  # 近10天RSI曾>70
    rsi_pullback = 45 <= t["rsi"] <= 55  # 当前RSI回落至45-55
    if rsi_was_strong and rsi_pullback and price > t["ma20"] and t["macd_status"] != "死叉":
        action, position_ratio, trade_type = pos._enter_position(today_str, price, "20%(回调入场)")
        self._update_entry_cost(pos, price, 0.20, code)
        return (action, position_ratio, trade_type, f"强势回调:RSI从>70回落至{t['rsi']},站MA20")
```

**为什么能解决"等确认后追高"**：
- 强势股上涨过程中必然经历回调，回调时 RSI 从高位（>70）回落到 45-55 区间
- 此时多头排列可能尚未形成或刚刚破坏，但价格仍站 MA20（中期趋势未破）
- 这比等 MA5>MA10>MA20 重新形成**早 3-8 个交易日**入场
- 本质是「买在趋势中的回调」，而非「买在趋势确认后」

**预期风险**：
- 回调可能演变为反转（RSI 继续下跌、跌破 MA20）
- 假回调（一日游反弹）会导致频繁小额止损

**如何验证**：
1. 在 `rsi_macd.py` 新增通道 0（需同步 `backtest_bt.py`）
2. 跑 2025 全年 + 2026 至今回测，对比基线
3. 关注指标：交易笔数是否增加、胜率是否下降、回撤是否扩大
4. 如果交易笔数大增但胜率显著下降 → 收紧 RSI 回调区间（如 48-52）
5. 如果交易笔数不变 → 说明 RSI 历史数据未正确传入，检查数据管道

### 建议 2：新增「MACD 零轴上金叉」早期通道

**具体修改**：
在多头排列检查之前，新增一个基于 MACD 零轴位置的早期入场通道：

```python
# 通道0: MACD零轴上金叉 (DIF>0 + 金叉，不要求多头排列)
if pos.build_phase == 0 and not bullish_align:
    dif_above_zero = t.get("macd_dif", 0) > 0  # DIF在零轴上方
    if dif_above_zero and t["macd_status"] == "金叉" and price > t["ma20"]:
        action, position_ratio, trade_type = pos._enter_position(today_str, price, "20%(MACD零轴)")
        self._update_entry_cost(pos, price, 0.20, code)
        return (action, position_ratio, trade_type, f"MACD零轴上金叉:DIF={t['macd_dif']:.4f},站MA20")
```

**为什么能解决"等确认后追高"**：
- MACD 的 DIF 上穿零轴 + 金叉，是比均线排列**更早**的趋势确认信号
- DIF>0 表示短期 EMA(12) > 长期 EMA(26)，趋势已经转多
- 此时 MA5>MA10>MA20 通常还要 3-5 天才能形成
- 加上 `price > MA20` 作为方向确认，过滤掉零轴下方的假金叉

**预期风险**：
- 零轴上方金叉在震荡市中可能反复出现（金叉→死叉→金叉），导致频繁交易
- 需要配合冷却机制防止过度交易

**如何验证**：
1. 检查 `market_data.py` 是否已计算 `macd_dif` 并传入 `t` 字典
2. 如果没有，需先在指标计算中添加 DIF 值传递
3. 跑 2025 全年 + 2026 至今回测
4. 关键指标：新通道触发次数、胜率、平均持仓天数
5. 如果触发次数过多且胜率 < 40% → 增加额外过滤（如要求 AO 上升）

### 建议 3：新增「成交量突破」入场通道

**具体修改**：
利用量比指标，新增成交量确认的突破入场通道：

```python
# 通道0: 成交量突破 (量比>1.5 + 价破MA20 + MA20斜率>0)
if pos.build_phase == 0 and not bullish_align:
    vol_ratio = t.get("vol_ratio", 1.0)  # 当日量/20日均量
    ma20_rising = False
    if t.get("ma20") and t.get("ma20_5ago"):
        ma20_rising = t["ma20"] > t["ma20_5ago"]
    
    if vol_ratio > 1.5 and price > t["ma20"] and ma20_rising and t["macd_status"] != "死叉":
        action, position_ratio, trade_type = pos._enter_position(today_str, price, "20%(量能突破)")
        self._update_entry_cost(pos, price, 0.20, code)
        return (action, position_ratio, trade_type, f"量能突破:量比{vol_ratio},MA20上升,站MA20")
```

**为什么能解决"等确认后追高"**：
- 成交量放大是趋势启动的**先行指标**——资金先进场，价格后跟上
- 放量突破 MA20 + MA20 斜率转正 = 趋势启动的早期信号
- 通常比多头排列早 5-10 个交易日出现
- 用成交量过滤假突破（无量突破往往是假信号）

**预期风险**：
- 放量可能是单日事件（利好出货、一日游）
- 需要确认量比数据在回测中可用（腾讯日线 K 线含成交量）
- MA20 斜率计算需要至少 25 个交易日数据

**如何验证**：
1. 确认 `vol_ratio` 和 `ma20_5ago` 在回测 `t` 字典中可用
2. 如果不可用，需先在 `market_data.py` 的日线指标计算中添加
3. 跑回测对比
4. 关键指标：通道触发次数、假突破率（入场后 5 天内跌破 MA20 的比例）

### 建议 4：放宽多头排列为「MA10>MA20 + 价>MA5」

**具体修改**：
将当前的 `MA5>MA10>MA20` 替换为更宽松但仍有序的排列条件：

```python
# 原: bullish_align = MA5 > MA10 > MA20
# 新: medium_align = MA10 > MA20 AND price > MA5
medium_align = (t.get("ma10") and t["ma20"] and t["ma10"] > t["ma20"] 
                and t["ma5"] and price > t["ma5"])
```

**为什么能解决"等确认后追高"**：
- `MA10 > MA20` 确认中期趋势向上（比 MA5>MA10 更稳定）
- `price > MA5` 确认短期价格在均线上方（比 MA5>MA10 更早触发）
- 之前测试的 `MA5>MA20`（去掉 MA10）失败了，因为 MA5 太敏感、MA20 太滞后，中间缺了 MA10 这个过渡
- 新条件 `MA10>MA20 + 价>MA5` 保留了 MA10 这个中期确认，但去掉了 MA5>MA10 这个最晚形成的关系
- 这是**之前失败方案的修正版**——不是简单去掉 MA10，而是用价格条件替代 MA5 排序

**预期风险**：
- 仍可能比完整多头排列引入更多假信号
- 但又比去掉 MA10 的方案（MA5>MA20）更稳健
- 如果仍然恶化，说明 MA5>MA10 这个关系是策略的核心护城河

**如何验证**：
1. 直接修改 `rsi_macd.py` L287 的 `bullish_align` 定义
2. 同步修改 `backtest_bt.py` L728 的对应检查
3. 跑 2025 全年 + 2026 至今回测
4. 如果 2025 年化下降 > 3% → 回滚，说明 MA5>MA10 不能动
5. 如果 2025 年化下降 < 1% 但 2026 提升 → 可保留

### 建议 5：新增「MA20 斜率转向 + MACD 红柱」入场通道

**具体修改**：
当 MA20 斜率从下降转为上升（或走平转上升）时，允许早期入场：

```python
# 通道0: MA20斜率转向 (MA20从下降→走平/上升 + MACD转红柱)
if pos.build_phase == 0 and not bullish_align:
    ma20_slope_now = None
    ma20_slope_prev = None
    if t.get("ma20") and t.get("ma20_5ago") and t.get("ma20_10ago"):
        ma20_slope_now = (t["ma20"] - t["ma20_5ago"]) / t["ma20_5ago"]
        ma20_slope_prev = (t["ma20_5ago"] - t["ma20_10ago"]) / t["ma20_10ago"]
    
    slope_turning = (ma20_slope_now is not None and ma20_slope_prev is not None 
                     and ma20_slope_now > -0.002 and ma20_slope_prev < -0.002)
    macd_turning = t["macd_status"] in ["红柱放大", "金叉"]
    
    if slope_turning and macd_turning and price > t["ma20"]:
        action, position_ratio, trade_type = pos._enter_position(today_str, price, "20%(斜率转向)")
        self._update_entry_cost(pos, price, 0.20, code)
        return (action, position_ratio, trade_type, f"MA20斜率转向:斜率从{ma20_slope_prev:.4f}→{ma20_slope_now:.4f},站MA20")
```

**为什么能解决"等确认后追高"**：
- MA20 斜率从负转正（或从下降转走平）是趋势反转的**最早信号**
- 此时价格可能刚开始站上 MA20，但 MA5>MA10>MA20 还需要 5-10 天才能形成
- 配合 MACD 转红柱/金叉作为动量确认，提高胜率
- 这个信号在 3 月半导体行情启动时应该能捕捉到

**预期风险**：
- MA20 斜率转向在震荡市中可能反复（今天转正明天转负）
- 需要 MA20_10ago 数据（回测中需确认可用）
- 斜率阈值 -0.002（即 5 天下降 1%）可能需要调优

**如何验证**：
1. 确认 `ma20_5ago` 和 `ma20_10ago` 在回测数据中可用
2. 跑 2025 全年 + 2026 至今回测
3. 特别关注 2026 年 3-4 月是否触发入场（半导体行情启动期）
4. 如果震荡市中触发过多 → 收紧斜率阈值（如 -0.005）

## 实施建议

### 优先级排序

| 优先级 | 建议 | 理由 |
|--------|------|------|
| 🥇 P0 | 建议 1：强势股回调 | 直接解决"追高"问题，有 skill 洞察支撑，逻辑最清晰 |
| 🥈 P0 | 建议 2：MACD 零轴上金叉 | 经典早期信号，MACD 数据已就绪，实现成本最低 |
| 🥉 P1 | 建议 4：放宽排列为 MA10>MA20+价>MA5 | 修正版方案，风险可控，但可能重蹈 MA5>MA20 覆辙 |
| 4 | P2 | 建议 3：成交量突破 | 新增维度，但需要确认数据可用性 |
| 5 | P2 | 建议 5：MA20 斜率转向 | 最早信号，但最易受震荡市干扰 |

### 实施原则

1. **每次只改一条**：逐条修改 → 回测验证 → 有效保留/无效回滚
2. **作为新增通道而非替换**：新通道放在多头排列检查之前，不影响现有 6 个通道
3. **初始仓位 20%**（而非 30%）：早期信号不确定性更高，用小仓位试探
4. **回测区间**：2025 全年 + 2026 至今，两个区间都要跑
5. **同步修改**：`rsi_macd.py` + `backtest_bt.py` 必须同步
