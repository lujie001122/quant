# 年化50%可行方案分析

**日期**: 2026-09-07  
**基线**: weekly-rotation 2y年化19.49%, 回撤6.19%  
**目标**: 年化50% (实盘对齐, 不做T, 不用杠杆)

---

## 一、核心结论

**年化50%在1.5年窗口内可达，但在2年/3年窗口内无法仅靠参数调优实现。**

关键发现：
1. **concentrated-pyramid** 是唯一接近50%年化的模式
2. 参数调优最多将2年年化从33%→42%，3年年化仍<25%
3. trail_pct=0.20 + top_n=3 + lookback=20 在1.5y达到**45.2%年化/9.2%回撤**
4. trail_pct=0.20 + top_n=3 + lookback=40 在1.5y达到**51.5%年化/8.3%回撤** (但3y回撤28.65%)
5. 要稳定达到50%，需要**模式+参数+代码优化**的组合拳

## 三、可行方案矩阵

### 方案A: 纯参数调优 (零代码改动)

| 方案 | 命令 | 2y年化 | 2y回撤 | 3y年化 | 3y回撤 | 评级 |
|------|------|--------|--------|--------|--------|------|
| A1-保守 | `--concentrated-pyramid --trail-pct=0.12 --top-n=3 --lookback=20` | 33.3% | 10.6% | 18.7% | 15.7% | ★★★ |
| A2-平衡 | `--concentrated-pyramid --trail-pct=0.15 --top-n=3 --lookback=20` | 33.5% | 10.2% | 20.0% | 15.7% | ★★★ |
| A3-激进 | `--concentrated-pyramid --trail-pct=0.20 --top-n=3 --lookback=20` | 37.7% | 10.5% | 22.5% | 19.8% | ★★☆ |
| A4-超激 | `--concentrated-pyramid --trail-pct=0.20 --top-n=3 --lookback=30` | 42.2% | 12.0% | 13.1% | 22.6% | ★★ |

**结论**: 纯参数调优在2y窗口年化上限约42%，在3y窗口约22%。**仅靠参数调优无法稳定达到50%。**

### 方案B: 参数调优 + 代码优化 (预计可达50%)

基于2y年化37.7% (方案A3)，叠加以下代码优化：

| 优化项 | 修改位置 | 预计增量 | 累计年化 | 风险 |
|--------|---------|---------|---------|------|
| 基线: A3参数 | 命令行参数 | — | 37.7% | — |
| 1. 防御盾独立判断 | rsi_macd.py check_defense | +2-3% | ~40% | 低 |
| 2. 多头排列放宽 MA5>MA20 | rsi_macd.py L211 + backtest_bt.py L689 | +3-5% | ~43-45% | 中 |
| 3. 浮盈止损上移(已有) | backtest_bt.py L589-596 | 已含 | — | — |
| 4. 动量衰减退出 | backtest_bt.py 集中模式换仓 | +2-3% | ~45-48% | 低 |
| 5. 弱市自适应仓位(大盘过滤) | 新增market_data + rsi_macd | +3-5% | ~48-53% | 中 |

**关键**: 第5项（大盘过滤）是最重要的——3y数据表明，20%+的回撤主要来自2023-2024熊市。如果在大盘<MA20时将建仓比例从50%→25%，可显著降低熊市亏损。

### 方案C: 模式切换策略 (市场自适应)

| 市场状态 | 判断条件 | 使用模式 | 预期年化 |
|---------|---------|---------|---------|
| 牛市 | 上证>MA20, MA20斜率>0 | concentrated-pyramid (tp=0.20, tn=3, lb=20) | ~45% |
| 震荡 | 上证≈MA20 | concentrated-pyramid (tp=0.12, tn=3, lb=20) | ~33% |
| 熊市 | 上证<MA20 | concentrated (tp=0.10, tn=2, lb=20) | ~20% |

**年化估算** (假设牛6月/震4月/熊2月): 
- 牛市: 1.225 × 1 = 1.225 (6月+22.5%)
- 震荡: 1.11 × 1 = 1.11 (4月+11%)
- 熊市: 1.033 × 1 = 1.033 (2月+3.3%)
- 综合: 1.225 × 1.11 × 1.033 ≈ 1.404 → **+40.4%/年**

加入动量衰减+防御盾独立后 → **预估+45-50%年化**

## 四、推荐实施路径

### Phase 1: 参数切换 (0改动, 5分钟)

**立即执行**: 从 weekly-rotation 切换到 concentrated-pyramid + 优化参数

```bash
# 回测验证
python3 backtest_bt.py --concentrated-pyramid --trail-pct=0.20 --top-n=3 --lookback=20 --start=2024-07-01 --end=2026-06-30
# 预期: 2y年化37.7%, 回撤10.5%
```

**实盘对齐修改**:
- config.yaml: `trail_pct: 0.20`
- config.yaml: `concentrated_top_n: 3`
- 实盘启动参数: `--concentrated-pyramid`

**风险**: 相比weekly-rotation, 回撤从6%→10.5%, 但年化从19%→37.7%

### Phase 2: 防御盾独立 (1天改动)

修改 `strategies/rsi_macd.py` 的 `check_defense()`:
- 返回值从 `bool` → `set[str]` (受影响的ETF集合)
- 同板块屏蔽，不同板块放行
- backtest_bt.py L664-682 已有独立判断逻辑，只需确认实盘同步

**预期**: 年化+2-3% → ~40%

### Phase 3: 多头排列放宽 (1天改动)

修改 `backtest_bt.py` L689:
```python
# 当前
if not (ma5_v and ma10_v and ma20_v and ma5_v > ma10_v > ma20_v):
# 改为
if not (ma5_v and ma20_v and ma5_v > ma20_v):
```

同步修改 `strategies/rsi_macd.py` L211

**预期**: 年化+3-5% → ~43-45%
**风险**: 震荡市假突破增加，需配合大盘过滤使用

### Phase 4: 大盘环境自适应 (3天改动, 关键)

新增逻辑:
1. `market_data.py` 新增 `fetch_index_klines()` 获取上证指数K线
2. `backtest_bt.py` concentrated-pyramid 建仓前检查大盘MA20
3. 大盘<MA20时: 建仓50%→25%, 或完全禁止新开仓

**预期**: 3y回撤从20%→13%, 年化+3-5% → **~48-50%**

### Phase 5: 动量衰减退出 (1天改动)

修改 `backtest_bt.py` 集中模式换仓逻辑:
- 从TOP3跌到TOP5: 减仓50%
- 跌出TOP6: 清仓 (当前逻辑)
- 新增: 跌出TOP4: 减仓50% (比当前跌出TOP6清仓更快反应)

**预期**: 年化+2-3% → **~50-53%**

## 五、风险警告

1. **50%年化需要牛市配合**: 3y数据表明，2024熊市年化仅0.12-22%，50%目标依赖市场环境
2. **top_n=4 + trail_pct=0.20 的55.8%年化不可靠**: 2y仅6笔交易, 3y回撤29%, 统计意义不足
3. **每一步优化需独立回测验证**: 不要同时改多个参数
4. **实盘与回测的滑点差异**: 回测用0.1%滑点, 实盘可能更高（尤其流动性差的ETF）
5. **金字塔加码在暴跌中放大亏损**: 需严格配合大盘过滤使用
