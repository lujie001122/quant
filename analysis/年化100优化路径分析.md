## 二、七维优化方案（按贡献排序）

### 【P0-必做】优化1：趋势中禁用网格卖出 → 预计贡献+10~20%年化

**问题根源**（利润流失报告已证实）：
- 网格策略在上涨趋势中持续触发卖出 → 持仓不断缩水
- 159516第1轮：网格卖出159,700股（70%持仓），最终移动止盈时只剩43,100股
- 网格卖出+确认加仓形成"卖低买高"循环

**具体方案**：
```python
# 在网格卖出判断中增加趋势过滤
if grid_signal != "无" and "卖出" in grid_signal and name not in self._order_pending:
    # 趋势中禁用网格卖出: 多头排列 + MA20斜率>0.5% → 不触发网格卖出
    if ma5_v and ma10_v and ma20_v and ma5_v > ma10_v > ma20_v:
        # 多头排列 → 不网格卖出，让利润奔跑
        continue
    if ps["trend_sell_today"] > 0:
        continue
    # ...原有网格卖出逻辑
```

**风险**：无趋势保护时回调更深，需配合移动止盈兜底。

### 【P0-必做】优化2：金字塔加仓（集中金字塔模式） → 预计贡献+15~25%年化

**问题根源**：当前集中模式只有init_pct=50%一次建仓，没有加码机制。

**具体方案**（已有concentrated_pyramid_mode参数，只需启用+调优）：

- 建仓50% → 浮盈5%加25% → 浮盈10%再加25% → 单ETF仓位达100%
- 跌出TOP_N*2则清仓

**回测命令**：
```bash

```

**风险**：加仓后回调幅度更大，需严格执行止损。

### 【P0-必做】优化3：放宽移动止盈trail_pct → 预计贡献+8~15%年化

**问题根源**：
- 当前trail_pct=12%：峰值回撤12%就清仓
- 159516清仓1(5/29@0.604)后20天涨至0.961（+59.1%）
- 策略空仓11天→追高15.4%回补

**具体方案**：
```
--trail-pct=0.18  (从12%放宽到18%)
```

**为什么18%合理**：
- 半导体ETF单日波动3-5%常见 → 12%回撤=2-4天正常回调
- 18%回撤=4-6天回调 → 能过滤大部分噪音但仍保护大趋势反转
- 当前硬止损25%作为最后兜底 → 18%和25%之间有7%缓冲

**回测命令**：
```bash
.venv/bin/python3 backtest_bt.py --concentrated --period=2y --trail-pct=0.18 --init-pct=0.50
```

### 【P1-推荐】优化4：缩短轮动周期 + 快速重新入场 → 预计贡献+5~15%年化

**问题根源**：
- rebalance=5天（每周轮动）→ TOP3排名变化后最多延迟5天才换仓
- cooldown=2天 → 止损后2天不能重新入场
- 清仓后空仓11天才重新入场（需等信号+通道条件满足）

**具体方案**：
```bash
--rebalance=1  # 每日重排名（但交易成本增加）
--stop-loss=0.10  # 止损从8%放宽到10%（减少假止损）
```

配合：冷却期从2天缩短到1天，趋势止盈清仓后如果仍为TOP3→下一交易日直接50%建仓。

**风险**：日度轮动交易成本增加（每5天→每天），需要验证成本vs收益。

### 【P1-推荐】优化5：新增强势回调入场通道 → 预计贡献+5~10%年化

**问题根源**（多头排列滞后追高报告已证实）：
- MA5>MA10>MA20是确认型指标，等确认时已涨5-15%
- 已证伪：去掉MA20、合并7通道→3通道、RSI>65防追高 → 全部失败
- 已证实正确方向：「池子仍按动量选强者，但入场时机等回调」

**具体方案**（在backtest_bt.py的集中模式中新增通道0）：
```python
# 通道0: 强势股回调入场 (不要求完整多头排列)
# 条件: RSI近期曾>70 + 当前RSI回落至45-55 + 站MA20 + 非死叉
if not entered and not bullish_align:
    rsi_was_strong = any(r > 70 for r in rsi_history[-10:])
    rsi_pullback = 45 <= rsi_val <= 55
    if rsi_was_strong and rsi_pullback and price > ma20_v and ms != "死叉":
        if self._buy(d, 0.50, f"强势回调50% RSI回落至{rsi_val:.1f}"):
            self._init_on_entry(ps, price)
            entered = True
```

**风险**：假回调→频繁小额止损，初始仓位20%更安全（但当前50%建仓已验证有效）。

## 九、核心结论

1. **年化100%不具备可持续性**：需要极端集中+极端运气，3年回测必然暴露弱点
2. **年化50-60%是可行目标**：金字塔加仓+禁用网格卖出+放宽止盈三管齐下
3. **年化70-90%是乐观上限**：需全部优化叠加，回撤可能20-25%
4. **最大单一优化**：趋势中禁用网格卖出（利润流失报告已证实在牛市中减仓70%是最大问题）
5. **最快见效优化**：金字塔加仓模式（已有参数，一条命令即可验证）
6. **2023年亏损的解决**：MA60大盘过滤+动态攻防配比（已有rotation.py逻辑，需集成到回测）
